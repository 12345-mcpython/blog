天赋：「尽情取悦本王吧」 / "Amuse Me to the Fullest"

  • 攻击类型: 无 · 效果: 强化 · 元素: 雷 · 最高等级: 15
  • 破韧值: 单体 0, 全体 0, 扩散 0

我方队友施放终结技时，吉尔伽美什获得【王来背负】，使自身造成的终结技伤害提高40%，持续3回合。
初始自身回合开始时自动施放普攻。我方其他目标行动时，吉尔伽美什获得1点【兴致】，每拥有1点【兴致】使自身速度提高10%。
当【兴致】首次达到10点时，进入【来兴致了！】状态，该状态下仅能施放战技，且持续整场战斗。施放战技后，清空自身【兴致】。

When a teammate uses their Ultimate, Gilgamesh gains "King's Burden," which increases Ultimate DMG dealt by this unit by 40%, lasting for 3 turn(s).
Initially, automatically uses Basic ATK at the start of this unit's turn. When another ally target takes action, Gilgamesh gains 1 point of "Interest." For each point of "Interest" in possession, increases this unit's SPD by 10%.
When "Interest" reaches 10 for the first time, enters the "Interest Piqued!" state. In that state, can only use Skill, lasting for the entire battle. After using Skill, clears this unit's "Interest."

When Gilgamesh or Saber attacks, the attack tally increases by 1. Then, Gilgamesh gains 3 "Interest." Saber regenerates a fixed 120 Energy, and the next time she uses Ultimate, the DMG dealt becomes 200% of the original DMG.
After using Joint Follow-Up ATK, resets the attack tally.
